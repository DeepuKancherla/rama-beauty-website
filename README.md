# Rama's LEVEL.R Beauty Studio Website

A modern responsive website for **Rama's LEVEL.R Beauty Studio** located in Vakalapudi, Andhra Pradesh.

## Features

- Responsive design
- Service showcase
- Gallery section
- Appointment booking form
- WhatsApp quick contact
- Mobile friendly layout

## Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
